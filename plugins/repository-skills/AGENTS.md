# AGENTS.md

This plugin owns reusable repository operations. Follow root Socket guidance for
general Git, release, dependency, and documentation rules.

## Scope

- Keep GitHub settings, repository maintenance, validation/release handoffs,
  and Codex GUI worktree mechanics here.
- Keep document content in `documentation-skills` and agent coordination
  contracts in `agent-engineering-skills`.
- Root `skills/` is the authored source of truth; plugin metadata is packaging.
